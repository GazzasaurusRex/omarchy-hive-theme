# Artwork provenance

The five cinematic wallpapers were created with OpenAI image generation from
original prompts written for this theme. They are compositions rather than
screenshots or extracted film/game assets. Prompts expressly excluded people,
actors, gore, movie still recreation, and watermarks.

- `01-emergency-corridor.png`
- `02-sterile-laboratory.png`
- `03-containment-door.png`
- `04-t-virus-laboratory.png`
- `05-red-queen-core.png`

The three interface wallpapers were authored as project SVG files and rendered
locally:

- `06-minimal-corporate.png`
- `07-facility-schematic.png`
- `08-cctv-surveillance.png`

Their SVG sources are retained under `docs/artwork-source/`.

The WAV cues are short synthetic tones created for the theme. They contain no
movie dialogue, soundtrack audio, or extracted sound effects.
